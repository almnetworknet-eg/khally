# خلي بالك من ابنك 🛡️ — نظام رقابة أبوية لأندرويد | almeng.net

نظام من **تطبيقين** + **سيرفر PHP/MySQL على استضافة cPanel بتاعتك** — كل البيانات عندك، من غير أي خدمة خارجية.

| الجزء | مكانه | دوره |
|---|---|---|
| **خلي بالك - ولي الأمر** (`parent`) | موبايل الأب/الأم | لوحة التحكم: القواعد، الأوامر، مشاهدة الشاشة |
| **خلي بالك** (`child`) | موبايل الابن | محرك الحماية: ينفّذ القواعد لحظياً |
| **API** (`server/`) | استضافة cPanel | يربط التطبيقين ويحفظ البيانات |

## المميزات

- 🚫 **حظر أي تطبيق** نهائياً
- ⏰ **حد يومي بالدقائق** لكل تطبيق (مثلاً يوتيوب ساعة في اليوم)
- 🕓 **فترة مسموحة يومياً** لكل تطبيق (مثلاً الألعاب من 4 لـ 6 العصر بس)
- 🌙 **وقت النوم**: قفل الجهاز تلقائياً كل يوم (مثلاً 10 بالليل لـ 7 الصبح)
- 🔒 **قفل الجهاز بالكامل** أو **قفل الشاشة فوراً** عن بُعد
- 📦 **منع تثبيت وحذف التطبيقات** (قفل Play Store ومثبّت الحزم)
- ⚙️ **قفل إعدادات الهاتف**
- 📺 **مشاهدة شاشة الابن لايف** (حوالي إطار في الثانية)
- 📊 وقت استخدام كل تطبيق اليوم + البطارية + التطبيق المفتوح الآن + آخر ظهور
- 🛡️ **حماية ذاتية**: يمنع تعطيل الحماية من الإعدادات، ويبعت تنبيه لولي الأمر لو حد حاول يوقفها

## التقنيات

Kotlin 2.1 • Jetpack Compose + Material 3 • Coroutines/Flow • PHP 8.1+ و MySQL على cPanel مع Long-polling (الأوامر توصل خلال ثانية من غير اتصال مفتوح دايماً) • AccessibilityService • UsageStatsManager • DevicePolicyManager (Device Admin / Device Owner) • واجهة عربية RTL كاملة.

```
KhallyBalak/
├── shared/   الموديلات المشتركة + الثيم + الأيقونة
├── parent/   تطبيق ولي الأمر
├── child/    تطبيق الابن
│   ├── GuardAccessibilityService.kt  ← محرك القفل والشاشة لايف
│   ├── UsageTracker.kt               ← حساب وقت الاستخدام
```

## خطوات التشغيل

### 1) تثبيت السيرفر تلقائياً (5 دقايق)
1. **قاعدة بيانات** — cPanel ← **MySQL Database Wizard**: اسم القاعدة `khally`، ومستخدم بكلمة مرور (احفظها)، وعلّم **ALL PRIVILEGES**.
2. **ارفع الملف** — cPanel ← **File Manager** ← افتح `public_html` ← **Upload** ← ارفع `khally-server.zip` ← كليك يمين عليه ← **Extract**.
3. **افتح المُثبّت** في المتصفح:
   `https://دومينك/khally/install.php`
   - هيفحص الاستضافة (PHP / MySQL / SSL) ويقولك لو فيه حاجة ناقصة وإزاي تصلحها.
   - اكتب بيانات قاعدة البيانات، واختيارياً بريد وكلمة مرور ولي الأمر.
   - اضغط **ثبّت الآن** ← هيعمل الجداول، ويحفظ الإعدادات، ويمسح نفسه للأمان.
4. هيظهر لك **عنوان السيرفر** اللي هتكتبه في التطبيقين (غالباً الدومين بس، مثل `mydomain.com`).

> لو الدومين مفيهوش SSL: cPanel ← **SSL/TLS Status** ← **Run AutoSSL**.

### 2) البناء
افتح المشروع في **Android Studio** واستنى الـ Sync، ثم Build ← **Build APK(s)** (أو Run على كل تطبيق).
**مش محتاج تعدّل أي كود** — عنوان السيرفر `almeng.net/app/khally` مكتوب جاهز في التطبيقين (ويمكن تغييره من نفس الخانة). للتغيير الافتراضي: `DEFAULT_ADDRESS` في `shared/.../Api.kt`.

### 3) الربط
1. في تطبيق ولي الأمر: اكتب **عنوان السيرفر** + بريدك وكلمة المرور ← دخول (أو حساب جديد) ← **إضافة جهاز ابن** ← اكتب الاسم ← هيظهر كود 8 حروف.
2. في تطبيق الابن: اكتب **نفس عنوان السيرفر** + الكود ← **ربط**.
3. فعّل الصلاحيات بالترتيب من نفس الشاشة: بيانات الاستخدام ← مسؤول الجهاز ← الإشعارات ← البطارية ← **خدمة الحماية**.
   - على أندرويد 13+ لو التطبيق متثبت من ملف APK هتظهر رسالة **"إعداد مقيّد"** عند تفعيل خدمة الحماية: افتح **معلومات التطبيق ← ⋮ (فوق) ← السماح بالإعدادات المقيدة** وارجع فعّلها.
4. هتظهر رسالة **"الجهاز محمي الآن ✅"**، وفي خلال 5 دقايق هتلاقي تطبيقات الابن ظاهرة عندك.

### 4) (اختياري — موصى به) الحماية القصوى: مالك الجهاز Device Owner
بدونها الابن الشاطر ممكن يعمل **إعادة ضبط مصنع**. مع وضع مالك الجهاز:
منع التثبيت/الحذف على مستوى النظام نفسه، منع إعادة ضبط المصنع، منع الوضع الآمن، منع تغيير الساعة للتحايل على الوقت، واستحالة حذف تطبيق الحماية.

الشرط: الجهاز **بدون أي حساب جوجل مضاف** وقت تنفيذ الأمر (يعني بعد ضبط المصنع مباشرة، أو احذف الحسابات مؤقتاً):
```bash
# فعّل خيارات المطور وتصحيح USB على موبايل الابن ثم وصّله بالكمبيوتر
adb install child-release.apk
adb shell dpm set-device-owner com.khallybalak.child/.AdminReceiver
```
بعدها أضف حساب جوجل عادي وكمّل الربط.

## إزاي الأوامر بتوصل بسرعة من غير Firebase؟
تطبيق الابن بيبعت طلب للسيرفر، والسيرفر **بيمسكه لحد 20 ثانية**: لو إنت غيّرت أي حاجة في الوقت ده، الرد بيرجع فوراً بالقواعد الجديدة (خلال ثانية تقريباً). لو مفيش جديد، يرجع بعد 20 ثانية والتطبيق يبعت طلب تاني. ده اسمه **Long-polling** وبيشتغل على أي استضافة عادية.
- لو النت قطع عند الابن، **آخر قواعد بتفضل شغالة** على الجهاز.
- كل جهاز ابن بيستخدم **عملية PHP واحدة** طول الوقت. الاستضافات المشتركة غالباً بتسمح بـ 20–30 عملية في نفس الوقت (Entry Processes)، فده كافي جداً لعيلة.

## ملاحظات مهمة (بصراحة)

- **الشاشة لايف** على أندرويد 11 أو أحدث، حوالي **إطار كل 1.2 ثانية** (صور مضغوطة ~40KB). أثناء المشاهدة بس، الاستهلاك تقريباً **2MB في الدقيقة** من باندويث الاستضافة. التطبيقات المحمية زي البنوك وNetflix بتظهر سوداء — قيد من أندرويد.
- لو ولي الأمر قفل شاشة البث أو التطبيق، البث بيقف لوحده خلال 15 ثانية.
- أثناء المشاهدة يظهر للابن إشعار **"ولي الأمر يشاهد الشاشة الآن"** — مقصود للشفافية.
- **الأمان**: كلمات المرور متشفرة (bcrypt)، التوكنات محفوظة كـ hash، كل الاستعلامات Prepared Statements، حماية من تخمين كلمة السر (10 محاولات/ربع ساعة)، والابن مايقدرش يعدّل القواعد. احتفظ بـ `config.php` سري ولا ترفع المشروع على GitHub ومعاه كلمة السر.
- **Google Play**: التطبيقات اللي بتستخدم Accessibility للرقابة الأبوية بتمر بمراجعة خاصة؛ للاستخدام العائلي التثبيت بملف APK كافي.
- شركات زي شاومي وأوبو وهواوي بتقفل التطبيقات في الخلفية: من إعدادات البطارية خلي "خلي بالك" **بدون قيود** وفعّل **التشغيل التلقائي**.

## أفكار للإصدار القادم
- موقع الابن على الخريطة (GPS) وسجل التحركات
- طلب "وقت إضافي" من الابن بإشعار لولي الأمر
- لوحة تحكم ويب على نفس الدومين
- فلترة المواقع الإباحية (VPN محلي + DNS آمن)
- تقرير أسبوعي بالرسوم البيانية
- بث فيديو سلس عبر WebRTC
